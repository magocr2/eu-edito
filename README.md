# Eu Edito · App Mobile (PWA Cloud)

Aplicativo web instalável para **iPhone e Android** que edita vídeos automaticamente na nuvem (funciona **mesmo sem GPU**, usando CPU) e entrega o vídeo pronto em **Original**, **1080p Full HD** ou **4K Ultra HD** + arquivo **.srt**.

## Como colocar no ar em 3 minutos (Render.com — funciona sem GPU)
1. Crie uma conta gratuita no **GitHub** (github.com) e crie um repositório novo (ex.: `eu-edito`) enviando os arquivos desta pasta `C:\Users\Hogus\Pictures\app`.
2. Crie uma conta no **Render.com** (render.com) → clique em **New +** → **Web Service** → conecte o repositório `eu-edito`.
3. O Render detecta o `Dockerfile` automaticamente (porta `8090`, plano CPU). Clique em **Create Web Service**.
4. Assim que ficar verde (`Live`), abra o link `https://eu-edito.onrender.com` no **Safari (iPhone)** ou **Chrome (Android)** e instale na Tela de Início!
