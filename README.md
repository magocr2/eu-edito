# Eu Edito · App Mobile (PWA)

Aplicativo web instalável para **iPhone e Android** que edita vídeos automaticamente na nuvem (16 GB RAM / CPU ou GPU) e entrega o vídeo pronto em **Original**, **1080p Full HD** ou **4K Ultra HD** + arquivo **.srt**.
